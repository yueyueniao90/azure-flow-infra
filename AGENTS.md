# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- Public repo: commit no subscription/tenant ID, email, token or secret. Stage files hold `"$AZFLOW_SUBSCRIPTION_ID"`, resolved at run time (see README, "Stage settings").
- Never run `az` for real from a worker: the captain's login is off limits. Validate offline only with `tests/run.sh` (shellcheck, Bicep build/lint, fake `az`/`gh`/`kubectl`/`kubelogin` in `tests/fake-bin`).
- Scripts must stay bash 3.2 compatible (macOS default): no associative arrays, no `mapfile`, no empty-array expansion under `set -u`.
- Cost rules: Free/Basic tiers, one AKS node, no monitoring, Key Vault or autoscaler. Role IDs live in `bootstrap/lib.sh` and `bicep/modules/`; `tests/test_bicep.sh` keeps them in sync with the seed's RBAC condition.
- The ABAC condition `bootstrap/seed.sh`'s `rbac_condition()` builds must quote the `ActionMatches{...}` action name as a single-quoted string literal (README, "Access model") — an unquoted action name shipped once and Azure rejects it outright with `InvalidCreateOrUpdateRoleAssignmentRequest`, a permanent failure `retry()` does not retry. `tests/fake-bin/az`'s `validate_condition()` catches this class of mistake offline; it is a minimal shape check, not a full ABAC parser.
- Federated-credential subjects must start with the `sub_claim_prefix` GitHub reports per repo (`seed.sh`'s `oidc_sub_prefix()`); never hand-build `repo:<owner>/<repo>`. With immutable subjects on, GitHub's tokens carry `owner@id/repo@id`, and a mismatched subject fails the pipeline's Azure login with `AADSTS700213` (README, "Access model").
- Pipeline (`.github/workflows/`) never uses a stored credential: every Azure job signs in over OIDC with a repository variable client ID (README, "The pipeline"). Pin every third-party action to a full commit SHA (resolve tags to SHAs with `gh api repos/<owner>/<repo>/tags`, not `gh api .../commits/<tag>`, which 404s on a tag ref). The logic each workflow runs lives in `ci/stage.sh` so it stays testable against the fake `az` (`tests/test_ci.sh`); keep new workflow behavior there rather than inline in YAML `run:` steps. `tests/test_workflows.sh` enforces the repo's workflow rules (pinned SHAs, no `pull_request_target`, no expression interpolated into `run:` shell, permissions least-privilege) with `actionlint` and grep checks; run `tests/run.sh` after editing any workflow.
- HTTPS (README, "HTTPS"): the Static Web App custom-domain binding and its DNS TXT validation are fully automated (`bicep/modules/static-web-app.bicep`, `ci/stage.sh dns-auth`, no new role). The deployment blocks until the `_dnsauth` TXT record exists, so `ci/stage.sh apply` must stay `--no-wait` + poll and write the record mid-deployment; a blocking `create` followed by a separate TXT step deadlocks until the job timeout. cert-manager on AKS is never installed by a pipeline identity — it needs cluster-admin-equivalent CRDs/ClusterRoles that no identity here holds or should hold — so it stays a manual, captain-run, once-per-cluster procedure in `bootstrap/cert-manager/README.md`; the `ClusterIssuer` YAMLs there are the only reviewable artifact of it. Don't add a pipeline step that runs `helm`/`kubectl` against a cluster without revisiting that decision first; the one read-only exception is `ci/stage.sh api-dns` below.
- Stage DNS records (README, "DNS records for the stage hosts"): the `webHost` CNAME is Bicep (`bicep/modules/dns-cname.bicep`); the `apiHost` A record is `ci/stage.sh api-dns`, because the application-routing ingress IP only exists on the `app-routing-system/nginx` Service. It reads that Service with `kubectl` after the infra identity self-grants AKS RBAC Reader on that one namespace, so any role `ci/stage.sh` assigns must also be in the seed's stage-group condition (`tests/test_bicep.sh` checks it). The apply job signs in again right before `api-dns`: `az` fetches new tokens with the GitHub OIDC token from sign-in, which expires within minutes (`AADSTS700024`).
